Build a modern, responsive web application called **“Smart Trip Planner – Manipur”** for the **Re-Imagining Manipur – Hackathon 2026**.

The website must be completely free to run and should use only free/open-source technologies. Can require free APIs, subscriptions, or API keys.

## MAIN PURPOSE

Create an intelligent tourism planner where a tourist enters their trip preferences and the website generates a personalized Manipur itinerary.

The planner should consider:

* Number of days
* Approximate budget
* Interests
* Travel style
* Number of people
* Preferred pace
* Starting location
* Food preferences
* Accessibility requirements

## LANDING PAGE

Create a visually attractive hero section:

**“Plan Your Perfect Manipur Journey”**

Subtitle:

**“Tell us what you love. We'll create a personalized Manipur experience for you.”**

Add a prominent button:

**“Create My Trip →”**

Use a clean tourism-inspired design with high-quality Manipur imagery, subtle animations and modern cards.

## SMART RECOMMENDATION SYSTEM

Create a destination database containing at least 15–20 Manipur destinations and experiences.

Each destination should have fields such as:

```text
name
category
description
location
estimatedCost
duration
interests
accessibility
ecoScore
bestTime
```

Use this dataset to dynamically generate itineraries.

Do not randomly select destinations.

The recommendation algorithm should prioritize destinations that match the user's selected interests and budget.
